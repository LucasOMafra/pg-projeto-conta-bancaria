# 💰 Projeto Conta Bancária

O **Projeto Conta Bancária** foi desenvolvido com base no aprendizado e aplicação dos conceitos de **Programação Orientada a Objetos (POO)** em **JavaScript** e **TypeScript**.  
Ao longo do curso, o projeto receberá novas funcionalidades em cada etapa, servindo como preparação para o **Projeto Final**, que consolida todos os conhecimentos adquiridos no primeiro bloco do bootcamp.

---

## 🧠 Objetivo do Projeto
Este projeto tem como principal objetivo **fixar os pilares da POO** e a estrutura de um sistema de contas bancárias, com foco em organização, boas práticas e escalabilidade.  
Entre os conceitos aplicados, estão:

- 🔹 Classes e Objetos  
- 🔹 Encapsulamento  
- 🔹 Herança  
- 🔹 Polimorfismo  
- 🔹 Métodos e atributos  
- 🔹 Tipagem estática (em TypeScript)

---

## 🧩 Estrutura do Código
O projeto é composto por classes que representam os principais elementos de um sistema bancário:

- **ContaBancaria** → classe base que define o comportamento padrão de uma conta  
- **ContaCorrente** e **ContaPoupanca** → classes derivadas com comportamentos específicos  
- Métodos de **depósito**, **saque** e **exibição de saldo**

---

## 🧱 Tecnologias Utilizadas
- 🟨 **JavaScript**
- 🔷 **TypeScript**
- ⚙️ **Node.js**
- 🧰 **readline-sync** (para interação via terminal)

---

## ▶️ Como Executar o Projeto

1. **Instale as dependências**:
   ```bash
   npm install
2. **Execute o código em TypeScript:**:
   ```bash
   ts-node ContaBancaria.ts
3. **Ou compile para JavaScript e execute:**:
   ```bash
   tsc  ContaBancaria.ts
   node ContaBancaria.js
